# KRAMA logo files

**Sequence K** retains the initial K and introduces short, stepped landings that suggest orderly progress. The upright provides structure; the branches express movement. Its meaning is a design interpretation informed by the name and the product's workflow.

## Use the right file

| File | Use |
| --- | --- |
| `logo-light.svg` / `.png` | Iris mark and Slate wordmark on white/light backgrounds |
| `logo-dark.svg` / `.png` | Light Iris mark and Platinum wordmark on Obsidian/dark backgrounds |
| `logo-black.svg` / `.png` | Single-color positive reproduction |
| `logo-white.svg` / `.png` | Single-color reversed reproduction |
| `mark-blue.svg`, `mark-black.svg`, `mark-white.svg` | Standalone symbol |
| `app-icon.svg` / `.png` | White mark in an Iris app-icon tile |
| `favicon.svg` / `.png` | Compact 16px application icon |
| `preview.svg` / `.png` | Presentation sheet; use the individual assets for production |

All production SVGs use filled shapes and outlined lettering. They do not need an installed font or an external linked resource. PNG versions of the logos and standalone marks have transparent backgrounds. The app icon has an intentional solid container, with transparent corners.

## Construction and use

- 48-unit symbol grid; 8-unit weight; 45-degree diagonals; 4-unit minimum internal gap.
- Minimum standalone symbol size: 16px. Minimum horizontal lockup height: 32px.
- Leave at least 8 symbol-grid units of external clear space around the artwork; retain the lockup proportions and intrinsic padding.
- Use Iris `#366BD3` on Paper `#FFFFFF`, or light Iris `#6290E7` on Obsidian `#151A22`. Do not add gradients, outlines, shadows or rotate the symbol.
- For one-color use, choose the provided black/white version rather than reducing opacity.
- The core geometry is identical across light, dark and monochrome versions.
